# M9-3b — 本編シートへの極性の割り当て（L5 で裏返して戻らない）

2026-08-26 / [Issue #59](https://github.com/bubbleShaker/lyric-stage/issues/59)

> **⚠ この割り当ては同日中に取り消した（[Issue #61](https://github.com/bubbleShaker/lyric-stage/issues/61)）。**
> 画を見て「反転は作品の狙いとずれていた」と判断したため。以下は取り消し前の記録。
> 仕組み（M9-3a）は残してあるので、割り当ては 1 行で戻せる。取り消しの理由は末尾を見よ。

## 何をしたか

M9-3a（#57）で入れた仕組みを本編シートに割り当てた。**コードの変更は JSON の 1 行と検査 1 本だけ**で、
本体は「どこで裏返すか」を画を見て決める作業。

```
  0    3     6     9    12    15    18    21       27
  |助走|綴れば|無限の|魔法が|世界が|believe|想いよ|輝き出す|
  ░░░░░░░░░░░░░░░░░░░░░░░░░░░░█████████████████████
                            ↑ L5（191.8 / 区間内 15.03s）で ink

  紙 15.03s ／ 墨 12.02s　切り替え 1 回
```

## なぜ L5 か

置き場所の候補は構造上 2 つしか無かった。

- **L5（15.03 秒）「I'll believe of my sensation」** — 7 行のうち唯一の英語の行で、尺 27.05 秒の
  ほぼ中央（55%）。構造の折り返しと歌詞の折り返しが重なる
- **L7（21.04 秒）「切なさやトキメキが輝き出す」** — 2 小節だけの山場

L5 を採った理由:

1. **切り替えが 1 回で済む。** 全画面の反転は明滅なので、回数はそのまま安全と画の落ち着きに効く
   （`MIN_POLARITY_INTERVAL` の下限には遠く及ばないが、少ないほど 1 回の重みが増す）
2. **山場が黒地に白文字で出る。**「輝き出す」は光が闇から現れる語なので、ink の側に置いた方が
   字義どおりになる。L7 で裏返すと**山場そのものが切り替えの音**になり、歌詞が読まれる前に
   画の変化へ注意が行く
3. **「信じる」瞬間に画が反転する**という読みが立つ。M9-1 が地を「退色した紙」に決めた以上、
   前半は綴る側・後半は信じた側、という対比になる

**L7 で紙へ戻す案（切り替え 2 回）は採らなかった。** 戻すと山場が「元に戻った」画になり、
**反転が往復する演出**に見える。M9 の主題は往復ではなく反転そのもの。

## 検査で守っているもの

**「作品のどこかで極性が切り替わる」を検査にした**（M8-3a の図形・M8-3c の英字と同じ穴）。
シートから `polarity` を消しても全テストが緑のまま、画は M9-2 のまま止まる ＝ M9-3 そのものが
静かに無効になる。

**見るのは `initial` ではなく `changes`。** 持ち越し（`sliceSheet`）で始まりの極性が立っている
だけの状態は「切り替わっている」ではない — 区間の外に書いた指定が区間の中では一度も動かない形に
なっていても、`initial` を見る検査は素通りしてしまう。

さらに**置き場所そのもの**も一段だけ固定した（レビュー指摘 🟡）。「どこかで切り替わる」だけだと、
極性を L1 へ移して**ほぼ全編を反転**させても緑のままで、M9-3b が採らないと決めた側が素通りする。

固定したのは PLAN の理由づけに対応する 2 つだけ:
- **最終行は墨の側**（「輝き出す」は光が闇から現れる語）
- **紙の側が尺の四半分以上残る**（`bg` は M9-1 で決めた作品の地なので、頭から裏返すと消える）

**ただしこれは L5 と L7 の区別まではしない。** 変異注入で確かめたところ、L7 へ移しても両方の
条件は成り立つ。L7 を採らなかったのは「山場そのものが切り替えの音になる」という**目で見た判断**で、
機械には見分けられない。検査が守るのは、その判断を下せる範囲から外へ出ていないことまで。

変異注入の結果:

| 変異 | 結果 |
|---|---|
| `polarity` を消す | 落ちる |
| 区間の外の行へ移す | 落ちる |
| `ink` → `paper` | 落ちる |
| L1（ほぼ全編が反転）へ移す | 落ちる |
| L7（墨が 6 秒だけ）へ移す | **通る**（上記のとおり、意図的に見分けていない） |

## 実測で確かめたこと

反転側に落ちる 3 行（L5 / L6 / L7）を描画して見た。M9-1 / M9-2 が地の明暗を前提に選んだ値が
残っているので、そこが崩れていないかが要点だった。

| 見たもの | 結果 |
|---|---|
| L5 の `glitch` の色ずれ（M9-1 が明るい地に合わせて選び直した対） | 反転側でも左右のフリンジが揃って出る |
| L5 の罫（`rule`） | 「I'll believe」の下で明るい線として読める |
| L6 の枠（`box`） | 「降り募る」を囲む輪郭が保たれる |
| L6 / L7 の英字（`sub`） | 読める（実測でも 5.12 → 6.82 と上がる段） |
| L7 の帯（`band`） | 「トキメキが」の下で明るい面になる（M9-2 で「紙を透かして刷られた面」になった図形が、反転側では下地を起こす形で出る） |
| L7 の縦組み（`vertical`） | 「切なさや」が罫とともに左上で成立 |

**どれも直しは要らなかった。** 特に L7 は「輝き出す」が白抜きで出るので、狙いどおり字義と画が一致する。

## つまずいたところ

- **`effect-preview.html` の `start()` のループは、任意のコマを撮る用途に使えない。** あれは毎フレーム
  `stage.render(elapsed)` を呼ぶので、**こちらが指定したコマを即座に上書きする**。
  `window.hold = true` を立ててもループ自体は止まらず、その時点の `elapsed`（headless では
  ほぼ 0）で描き続ける ＝ **演出の開始状態、つまり文字が透明なコマが写る**。
  DOM を吐かせると `opacity: 1` で正しく置かれているのに画が空、という食い違いになって
  原因が読めなくなる。任意のコマを撮るときは `stage.show(line)` → `stage.render(t)` を直に呼ぶ

## 取り消し（Issue #61）

公開した画を見た作者の感想:

- 後半 12 秒が墨のままなのが重い
- 切り替わる瞬間が唐突
- 反転した側の画自体が好みでない
- **そもそも期待していたのは反転ではなかった** — 「語句に合わせてパッと装飾が出て、弾けて消える」
  ポップな演出（色は差し色の朱）を思い描いていた

**4 つ目が本質。** 量やタイミングの調整では埋まらないので、割り当てごと落とした。

### 残したもの・落としたもの

| | 扱い |
|---|---|
| `polarity` の割り当て（JSON 1 行） | 落とす |
| 仕組み（`.scene` / `filter: invert(1)` / `polarity` の口 / domain の検査） | **残す**（1 行で戻せる状態にしておく方が価値がある） |
| 「作品のどこかで切り替わる」「山場は墨の側」の検査 | 落とす（割り当てが在ることを前提にしており、今は主張そのものが誤り） |
| `findRapidPolarityFlip`（明滅の安全） | **残す**（今は自明に緑だが、極性が戻った日に効く番人） |

### 教訓

**主題を 3 段に分けて積む前に、1 段目で画を見てもらうべきだった。** M9 は「明暗の反転」を
配色の反転 → 刷り重ね → 動的な反転と積み上げたが、**主題そのものが狙いとずれていた**。
M9-1 の時点で画を見せていれば、引き返す幅が 3 段ぶんではなく 1 段で済んだ。
分けて刻むこと自体は正しく、**刻みの単位ごとに作者の目を通す**のが足りていなかった。

なお M9-1 / M9-2（退色した紙の地と乗算）は気に入られているので残す。

## 次

「パッと出て弾けて消える装飾」を別の題材として起こす。今の `decor`（帯・罫・枠）は
**語句をそこに留めるための静的な重み**で、出たら行が終わるまで残る。求められているのは
**一過性の装飾**なので、同じ語彙には収まらない。
